# Shift Tracker CLI

Лёгкий и быстрый консольный инструмент для учёта рабочих смен и расчёта заработной платы. Позволяет добавлять смены, автоматически считает итоговый заработок на основе часов и ставки, а также выводит детальную статистику по месяцам.

## 🚀 Запуск

1. Клонируйте репозиторий:
```bash
   git clone https://github.com/genius333/shift-tracker.git
   cd shift-tracker
```
2. Убедитесь, что у вас установлен Python 3.8+:
```bash
   python3 --version
```
3. Запустите приложение:
```bash
   python3 main.py
```

## ⚙️ Настройка и хранение данных

- Программа не требует настройки API-ключей или сложных конфигов.
- Все данные автоматически сохраняются в локальную базу данных SQLite. Файл создаётся в скрытой папке вашего пользователя:
  - **Windows**: `C:\Users\<Username>\.shift_tracker\data.db`
  - **macOS/Linux**: `~/.shift_tracker/data.db`
- Рекомендуется периодически делать резервную копию этого файла.

## 🛠 Технологии

- **Язык**: Python 3.8+
- **База данных**: SQLite (встроенная, `sqlite3`)
- **Архитектура**: Модульная (разделение логики БД и CLI), DRY, строгая типизация (`typing`), обработка крайних случаев (валидация ввода, try/except), ранние возвраты (early return).

## 📋 Возможности

- ✅ Валидация дат и числовых значений (защита от некорректного ввода).
- ✅ Автоматический расчёт заработка (`часы * ставка`).
- ✅ Обновление существующей смены при повторном вводе той же даты (UPSERT).
- ✅ Подсчёт общих часов и суммы за выбранный месяц с детализацией.
- ✅ Кроссплатформенность (Windows, macOS, Linux).
